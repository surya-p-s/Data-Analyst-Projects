# HR Employee Attrition Analysis Dashboard

## 📌 Project Overview

Employee attrition is one of the most important challenges faced by organizations. High attrition can increase recruitment costs, impact productivity, and reduce employee morale.

This project analyzes HR employee data to identify key factors contributing to employee attrition and provides actionable insights through an interactive dashboard. The analysis helps HR teams understand workforce trends, identify high-risk employee segments, and support data-driven retention strategies.

---

## 🎯 Objectives

- Analyze employee attrition patterns.
- Identify departments, job roles, and demographic groups with high attrition.
- Understand the impact of factors such as age, salary, education, job satisfaction, and work-life balance.
- Provide actionable recommendations to improve employee retention.
- Build an interactive dashboard for HR decision-making.
