# Sales Data Dashboard

## 📌 Project Overview

The Sales Data Dashboard is a Power BI project designed to analyse sales performance, profitability, and customer trends. The dashboard transforms raw sales data into insightful visualisations, enabling businesses to monitor key performance indicators, identify growth opportunities, and make data-driven decisions.

By analysing revenue, profit, orders, and product performance across multiple dimensions, the dashboard provides a comprehensive view of business performance and supports strategic planning.

---

## 🎯 Objectives

- Analyse overall sales and profitability trends.
- Track business performance through key sales KPIs.
- Identify top-performing products and categories.
- Understand customer and regional sales patterns.
- Support data-driven decision-making with interactive visualisations.

---

## 🛠 Tools & Technologies

- **Power BI** – Dashboard Development & Data Visualization
- **Power Query** – Data Cleaning & Transformation
- **DAX** – KPI Calculations and Measures
- **Excel / CSV** – Data Source
