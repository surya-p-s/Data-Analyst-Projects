# 📊 Data Analyst Projects Portfolio

Welcome to my Data Analytics Portfolio repository! This repository showcases a collection of end-to-end data analytics and business intelligence projects developed using Power BI, SQL, Python, Excel, and IoT technologies. Each project focuses on solving real-world business problems through data cleaning, analysis, visualization, and insight generation.

These projects demonstrate my ability to transform raw data into actionable insights, build interactive dashboards, and support data-driven decision-making across multiple domains including Sales, Finance, Human Resources, and Smart Manufacturing.

---

## 🚀 Featured Projects

### 📈 Sales Data Dashboard
A Power BI dashboard designed to analyse sales performance, profitability, customer behaviour, and regional trends. The project provides key insights into revenue growth, product performance, and business opportunities.

**Skills:** Power BI, DAX, Data Modelling, Sales Analytics, KPI Tracking

---

### 💰 Loan Data Dashboard
A financial analytics project focused on loan applications, funding performance, borrower profiles, and portfolio health. The dashboard supports risk assessment and lending decision-making through comprehensive KPI analysis.

**Skills:** Financial Analytics, Power BI, DAX, Data Transformation, Business Intelligence

---

### 👥 HR Employee Attrition Dashboard
An HR analytics solution that explores employee turnover patterns and identifies factors influencing attrition. The dashboard helps organizations improve retention strategies through workforce insights.

**Skills:** HR Analytics, Power BI, Data Visualization, Workforce Analysis

---

### 🏭 SmartFactory Pulse
An Industrial IoT monitoring platform built to track machine health, production performance, and operational efficiency in real time. The solution collects sensor data, stores it in PostgreSQL/TimescaleDB, and visualizes key metrics through interactive Grafana dashboards. It enables predictive maintenance, anomaly detection, and data-driven decision-making in smart manufacturing environments.

**Skills:** Grafana, PostgreSQL, TimescaleDB, Python, IoT Analytics, Real-Time Monitoring, Data Engineering, Predictive Maintenanceent
