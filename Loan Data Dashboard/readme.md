# Loan Data Dashboard

## 📌 Project Overview

The Loan Data Dashboard is a Power BI project designed to analyse loan application and lending performance data. The dashboard provides a comprehensive view of key loan metrics, borrower characteristics, and loan portfolio performance, enabling stakeholders to make data-driven financial decisions.

Through interactive visualisations and KPI tracking, the dashboard helps identify approval trends, loan repayment behaviour, risk patterns, and performance indicators across different customer segments.

---

## 🎯 Objectives

- Analyse loan application trends and approval rates.
- Monitor funded and received loan amounts.
- Identify high-performing and high-risk loan segments.
- Evaluate borrower profiles and lending patterns.
- Support data-driven decision-making for loan management.

---

## 🛠 Tools & Technologies

- **Power BI** – Dashboard Development
- **Power Query** – Data Cleaning & Transformation
- **DAX** – KPI Calculations and Measures
- **Excel / CSV** – Data Source

---

## 📊 Key Performance Indicators (KPIs)

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income (DTI) Ratio
- Good Loan Percentage
- Bad Loan Percentage
- Loan Approval Rate
